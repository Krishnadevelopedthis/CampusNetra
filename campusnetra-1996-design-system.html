System Rules: Do's and Don'ts INTEGRITY

✓ MANDATORY PRACTICES

  • Page Frame: Keep the literal 8px black border on every page container.
  • Dell Red Constraint: Reserve #e91d2a strictly for the single Red CTA block and top phone callout.
  • Catalog Family Tints: Use the 8 flat tints (Sage, Salmon, Peach, etc.) across product ribbon cards.
  • Display Weight: Set all primary section headers in Arial Black 900 all-caps.
  • Body Serifs: Keep all descriptive copy in Times New Roman 14px.
  • Hard Bevels: Use 1px highlight/shadow borders and hard drop-shadows on stickers & photos.

✗ STRICTLY FORBIDDEN

  • No Modern Radii: Never add border-radius: 4px/8px/12px (everything is 0px except circular award seals).
  • No Soft CSS Shadows: Never use blurry box-shadow: 0 4px 20px rgba(...) or atmospheric gradients.
  • No Sans-Serif Body: Never replace Times Roman body with modern sans (Inter, Roboto, Arial).
  • No Extra Chromatics: Do not introduce colors outside the 8 catalog tints + Red + Yellow + Blue.
  • No Multiple Red CTAs: Never place more than one Red CTA block on a page.
  • No Touch-First Micro-Sizing: Preserve 1996 dense table layouts while meeting touch accessibility on mobile.
